Projects

Featured Project

B2B Churn Prediction and Analysis

Built to predict B2B customer churn before a cancellation request ever happens. I used SQL to extract behavioral patterns from raw usage data, trained a Random Forest model to flag at-risk accounts, and deployed the final predictions into a live Streamlit app so the Customer Success team can take action.

SQL Python scikit-learn Streamlit Power BI
Key Insight

A 65% drop in platform activity and a heavy reliance on a single "champion" user are the strongest predictors of churn. By tracking these specific behaviors, the model flagged 241 active high-risk accounts, isolating $521,000 in monthly recurring revenue for early intervention.
